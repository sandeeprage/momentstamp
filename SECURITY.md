# Security reporting

Please report security issues privately. If GitHub private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on the [Security tab](https://github.com/sandeeprage/momentstamp/security). Otherwise, contact the repository owner privately through GitHub before disclosing the issue publicly.

Do not open a public issue containing an exploitable vulnerability, invite link, participant identifier, photo, or TURN credential. Include the affected page or endpoint, the impact, and steps to reproduce without real user data.
